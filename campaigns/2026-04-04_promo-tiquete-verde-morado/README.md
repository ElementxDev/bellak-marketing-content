## 🖼️ CONCEPTO DEL FLYER

### Concepto Principal: **"LA ESCALERA DE PREMIOS"**

**Idea visual:**
Mostrar una escalera (o staircase) donde cada peldaño representa B/.10:

```
          🎁 ¡GRATIS!
         /
   🟢🟣 — Peldaño B/.40 → 4 prendas gratis
       /
   🟢🟣 — Peldaño B/.30 → 3 prendas gratis
     /
   🟢🟣 — Peldaño B/.20 → 2 prendas gratis
   /
🟢🟣 — Peldaño B/.10 → 1 prenda gratis
```

**Psicología:** El cliente ve que "ya casi llega al siguiente nivel" y añade más al carrito.

---

### Concepto Alternativo: **"EL BILLETE GANADOR"**

**Idea visual:**
Diseñar el flyer con la estética de un billete o cupón de lotería / "golden ticket":
- Fondo con textura de billete (dorado o con patrón clásico)
- Texto central: **"VALE 1 PRENDA GRATIS"**
- Subtítulo: *"Por cada B/.10 de compra"*
- Colores destacados: verde 🟢 y morado 🟣 como sellos de premio
- Footer: **"Sáb 4 – Mar 7 de abril | Todas las tiendas"**

**Psicología:** La metáfora del "billete ganador" despierta emoción de lotería — el cliente siente que ya ganó y solo necesita hacer la compra para cobrar su premio.

---

### Concepto Alternativo 2: **"SHOPPING METER / MEDIDOR DE PREMIOS"**

**Idea visual:**
Un medidor estilo termómetro o barra de progreso:
- La barra se "llena" cada B/.10
- Cada segmento de B/.10 tiene un ícono de prenda verde/morada al lado
- El título encima: **"¡Entre más compras, más ganas!"**

**Psicología:** Los medidores de progreso generan el efecto "goal gradient" — el cliente quiere completar la barra.

## 🎨 LINEAMIENTOS DE DISEÑO DEL FLYER

### Colores
- **Fondo**: Negro (#000000) o blanco (#FFFFFF) para máximo contraste
- **Tiquete Verde**: #2ECC71 o #27AE60
- **Tiquete Morado**: #8E44AD o #9B59B6
- **Acento dorado**: #F1C40F (para destacar "GRATIS" y precios)
- **Texto principal**: Blanco (si fondo negro) / Negro (si fondo blanco)

### Tipografía
- **Titular**: Bebas Neue o Montserrat Black — tamaño grande, bold, impactante
- **Precio B/.10**: Muy grande, color dorado o blanco, debe ser el elemento más visible
- **Cuerpo**: Montserrat Medium o Open Sans

### Elementos Visuales Clave
1. **Tiquetes de precio reales** (verde y morado) — usar fotos reales o vectores muy realistas
2. **Número "10"** — debe ser el elemento más prominente del diseño
3. **Prendas colgadas** o en perchero — crea contexto de moda/tienda
4. **Signo B/. (Balboa)** — claridad de moneda local

### Formato
- **Instagram Feed**: 1080x1080px (cuadrado) — versión principal
- **Instagram Stories / TikTok**: 1080x1920px (vertical) — para stories y reels
- **WhatsApp**: 800x800px — para difusión por grupos

### Jerarquía visual del flyer (de más a menos prominente):
1. 🥇 El número **"10"** y **"B/."** (la mecánica en 2 segundos)
2. 🥈 **"GRATIS"** en color dorado o neón
3. 🥉 Los tiquetes **VERDE** y **MORADO**
4. Fechas
5. Nombre de las tiendas / logo

## 🧠 ESTRATEGIA PARA GENERAR COMPRAS DE B/.10 EN B/.10

### 1. Muestra el "costo por regalo" claramente
El cliente debe entender: **"Por solo B/.10 más, me llevo OTRA prenda gratis"**.
Usa frases como:
> *"¿Te faltaron B/.5? Añade cualquier artículo de B/.5 y te llevas tu prenda gratis"*

### 2. Sticker de "¿Cuánto llevas?" para el punto de venta
Crear un cartel en caja con el medidor:
- B/.10 → ⭕ 1 gratis
- B/.20 → ⭕⭕ 2 gratis
- B/.30 → ⭕⭕⭕ 3 gratis
- B/.40 → ⭕⭕⭕⭕ 4 gratis

### 3. Mensaje de vendedor en caja
Capacitar al personal para decir:
> *"¡Tu compra es de B/.27! Si añades solo B/.3 más, llevas DOS prendas de tiquete verde o morado gratis en vez de una 😊"*

### 4. CTA en Stories
Usar la función de **cuenta regresiva** de Instagram para las 4 fechas.
Sticker de pregunta: *"¿Cuántas prendas gratis vas a llevarte? 👀"*
