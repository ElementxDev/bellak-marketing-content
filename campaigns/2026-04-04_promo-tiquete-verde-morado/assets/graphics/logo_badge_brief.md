# 🏷️ Brief del Logo/Badge — "Lleva una gratis por cada B/. 10 en compras"

**Campaña**: Promo Tiquete Verde y Morado
**Vigencia**: Sábado 4 al Martes 7 de abril, 2026

---

## 🎯 Propósito del Logo/Badge

Este badge es el **sello de identidad visual de la promoción**. Debe:
- Comunicar la mecánica en un solo vistazo
- Funcionar en el flyer, en stories, en etiquetas físicas y en video
- Ser reconocible y repetible en todos los materiales
- Incorporar los colores de tiquete (verde 🟢 y morado 🟣)

---

## 📐 OPCIONES DE FORMA DEL BADGE

### Opción A — **Círculo Tipo Sello** ⭐ RECOMENDADA
La forma más clásica para badges de promoción. Transmite **oficialidad y confianza**.

```
     ╭──────────────────────╮
    ╱   🟢  LLEVA UNA  🟣    ╲
   │        G R A T I S       │
   │   ═══════════════════    │
   │    por cada B/. 10       │
   │       en compras         │
    ╲                        ╱
     ╰──────────────────────╯
```

**Especificaciones:**
| Elemento | Valor |
|----------|-------|
| Forma | Círculo o elipse |
| Fondo | Verde `#27AE60` o Morado `#8E44AD` |
| Borde exterior | Doble línea blanca (estilo sello) |
| "LLEVA UNA" | Montserrat Black / Bebas Neue, blanco, arco superior |
| "GRATIS" | Bebas Neue, blanco, el texto más grande, centro |
| "por cada B/.10 en compras" | Montserrat Medium, blanco/amarillo, arco inferior o línea recta |
| Íconos de tiquete | 🟢 izquierda y 🟣 derecha, flanqueando "GRATIS" |

---

### Opción B — **Burst / Explosión** (Starburst) 🌟
Forma de estrella o explosión — comunica **impacto, oferta irresistible**.

```
        ★ ★ ★ ★ ★
      ★             ★
    ★   LLEVA UNA    ★
   ★      GRATIS      ★
    ★   por cada B/.10  ★
      ★  en compras  ★
        ★ ★ ★ ★ ★
```

**Especificaciones:**
| Elemento | Valor |
|----------|-------|
| Forma | Starburst de 12-16 puntas |
| Fondo | Amarillo dorado `#F1C40F` (máximo impacto) |
| Contorno | Verde o Morado |
| "GRATIS" | Rojo `#E74C3C` o Negro, Bebas Neue, texto más grande |
| "por cada B/.10" | Negro, Montserrat Bold |
| Uso ideal | Sticker sobre fotos de productos, esquina del flyer |

---

### Opción C — **Etiqueta Colgante** (Tag Shape) 🏷️
Simula una **etiqueta de precio real** — conecta directamente con los tiquetes físicos de la tienda.

```
   ╭───────────────────╮
   │  🟢 LLEVA UNA 🟣  │
   │    ━━━━━━━━━━━━   │  ← tira diagonal
   │  G  R  A  T  I  S │
   │    ━━━━━━━━━━━━   │
   │  x cada B/. 10    │
   │   en compras      │
   ╰────────────o──────╯
                ↑
           agujero del tiquete
```

**Especificaciones:**
| Elemento | Valor |
|----------|-------|
| Forma | Rectángulo redondeado con "perforación" en la esquina superior |
| Fondo | Verde `#27AE60` (lado izquierdo) + Morado `#8E44AD` (lado derecho), dividido diagonal |
| "GRATIS" | Blanco, Bebas Neue, centro, texto dominante |
| Borde | Blanco, línea punteada (simula corte de tiquete) |
| Círculo perforación | Blanco sólido, esquina superior derecha |
| Uso ideal | Flyer principal, ideal para imprimir y colgar en tienda |

---

### Opción D — **Escudo / Shield** 🛡️
Transmite **garantía y solidez**. Buen balance entre impacto y elegancia.

```
      ╭────────────────╮
     /  LLEVA UNA 🟢🟣  \
    │     ─────────     │
    │      G R A T I S  │
    │     ─────────     │
    │  x cada B/. 10    │
     \   en compras    /
      ╰────────────────╯
              │
              ▼ (punta del escudo)
```

**Especificaciones:**
| Elemento | Valor |
|----------|-------|
| Forma | Escudo clásico (ancho arriba, termina en punta abajo) |
| Fondo | Mitad verde / mitad morado, dividido verticalmente |
| "GRATIS" | Blanco, Bebas Neue, oversized |
| Borde | Blanco, 3-4px |

## 🎨 JERARQUÍA VISUAL DEL BADGE (para cualquier opción)

El ojo debe leer en este orden:

```
1️⃣  GRATIS          ← texto más grande y llamativo
2️⃣  B/. 10          ← número en negrita, segundo más prominente
3️⃣  Lleva una       ← contexto
4️⃣  en compras      ← cierre
```

## 🛠️ CÓMO HACERLO EN CANVA (paso a paso)

1. Abre Canva → Crear diseño → **Tamaño personalizado** → 500x500px
2. Añade un elemento de **forma**: círculo o starburst (busca "burst" en elementos)
3. Rellena con color verde `#27AE60` o morado `#8E44AD`
4. Añade texto:
   - Línea 1: `Lleva una` (Montserrat SemiBold, 40px, blanco)
   - Línea 2: `GRATIS` (Bebas Neue, 120px, blanco — el más grande)
   - Línea 3: `por cada B/. 10` (Montserrat Bold, 50px, amarillo dorado)
   - Línea 4: `en compras` (Montserrat Regular, 35px, blanco)
5. Añade borde doble: `Efectos → Contorno` (color blanco, 8px)
6. Descarga como **PNG con fondo transparente**
